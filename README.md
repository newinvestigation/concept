# 채팅창 타일러 (Chat Window Tiler)

브라우저에서 여러 개의 채팅창(예: band.us 팝업창)을 동시에 열어놓고 모니터링할 때,
창들이 서로 겹치지 않도록 **원하는 비율의 구역으로 한 화면에 자동 정렬**해주는
Chrome/Edge 확장 프로그램입니다.

브라우저 확장은 `chrome.windows` API로 이미 열려 있는 창들의 위치와 크기를 직접
제어할 수 있기 때문에, 창 제목(band.us 채팅방 이름 등)을 기준으로 원하는 창들만
골라서 격자(grid)나 사용자 정의 구역에 자동 배치할 수 있습니다.

## 주요 기능

- **빠른 타일 배치**: 행×열 숫자만 입력하면 균등한 격자로 즉시 정렬
- **제목 필터**: "band.us" 같은 문자열로 대상 창만 골라서 배치 (다른 창은 건드리지 않음)
- **원하는 비율의 사용자 정의 레이아웃**: 구역 관리 화면에서 사각형을 마우스로
  드래그(이동)·리사이즈(크기 조절)해서 원하는 비율로 화면을 나누고, 이름 붙여 저장
- **레이아웃 저장/재사용**: 저장해둔 레이아웃을 팝업에서 언제든 한 번에 다시 적용
- **배치 순서 조정**: 어떤 창이 몇 번 구역에 들어갈지 적용 전에 화살표로 순서 변경
- **다중 모니터 지원**: 배치할 모니터를 선택 가능 (`system.display` API 사용)
- **단축키**: `Ctrl+Shift+L` (Mac: `Cmd+Shift+L`)로 마지막에 적용한 레이아웃을
  현재 열려 있는 창들에 즉시 재적용

## 설치 방법 (개발자 모드로 압축해제된 확장 프로그램 로드)

1. Chrome/Edge 주소창에 `chrome://extensions` (Edge는 `edge://extensions`) 입력
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭
4. 이 저장소의 `extension` 폴더 선택
5. 툴바에 확장 아이콘이 생성되면 완료

크롬 웹스토어에 올리지 않고 로컬에서 바로 사용하는 방식이라 별도 심사나 배포
과정 없이 바로 쓸 수 있습니다.

## 사용 방법

### 1) 빠르게 격자로 정렬하기
1. 툴바 아이콘 클릭 → 팝업 열림
2. "빠른 타일 배치"에서 행/열 입력 (예: 2행 3열이면 창 6개를 2x3으로 배치)
3. "창 제목 필터"에 `band.us` 처럼 대상 창을 구분할 문자열 입력 (비워두면 열려있는
   모든 창이 대상)
4. 배치할 모니터 선택 후 **이 조건으로 창 찾기** 클릭
5. 찾은 창 목록이 순서대로 표시됨 → 필요하면 ▲▼ 버튼으로 순서 조정
6. **이 순서로 적용** 클릭 → 즉시 화면에 격자로 재배치됨

### 2) 원하는 비율로 직접 구역 만들기
1. 팝업의 ⚙ 아이콘 또는 "레이아웃 관리 열기" 클릭 → 전체 탭으로 레이아웃 편집기 열림
2. 프리셋(2x2, 세로 3분할, 메인+사이드 등)으로 시작하거나 "+ 구역 추가"로 빈 사각형 추가
3. 사각형을 드래그해서 위치를 옮기고, 오른쪽 아래 모서리를 드래그해서 크기(비율) 조절
4. 필요하면 좌측의 X%/Y%/너비%/높이% 입력창으로 정밀하게 수치 입력
5. 이름을 입력하고 **현재 구성 저장**
6. 팝업으로 돌아가면 "저장된 레이아웃" 목록에 나타나고, **적용** 버튼으로 언제든 재사용

### 3) 마지막 레이아웃 즉시 재적용
- 창을 새로 몇 개 더 열었거나 다시 정렬하고 싶을 때 `Ctrl+Shift+L`을 누르면,
  마지막에 사용한 레이아웃과 제목 필터 조건으로 현재 열려 있는 창들을 다시
  찾아서 자동 배치합니다.

## 동작 원리 (간단 설명)

- `chrome.windows.getAll()`로 열려 있는 모든 브라우저 창 목록을 가져오고,
  `chrome.tabs`의 제목/URL로 필터링합니다.
- 레이아웃은 화면 비율(0~1 사이의 X/Y/너비/높이)로 저장되므로, 어떤 해상도의
  모니터에도 동일한 비율로 적용됩니다 (`chrome.system.display.getInfo()`로
  선택한 모니터의 작업 영역 크기를 가져와 실제 픽셀 좌표로 환산).
- `chrome.windows.update()`로 각 창을 계산된 위치/크기로 이동시킵니다
  (최대화/최소화 상태인 창은 먼저 `normal` 상태로 되돌린 뒤 이동합니다).

## 개인정보 관련

- 이 확장은 열려 있는 창의 **제목과 URL**을 읽어서 필터링에 사용할 뿐,
  어떠한 외부 서버로도 데이터를 전송하지 않습니다. 저장된 레이아웃/설정은
  브라우저 로컬 저장소(`chrome.storage.local`)에만 보관됩니다.

## 폴더 구조

```
extension/
  manifest.json     확장 프로그램 정의 (Manifest V3)
  background.js     단축키(Ctrl+Shift+L) 처리용 서비스 워커
  common.js         창 조회/필터, 레이아웃 계산, 저장 등 공통 로직
  popup.html/js/css 툴바 팝업: 빠른 타일 배치, 저장된 레이아웃 적용
  options.html/js/css  레이아웃 관리 화면: 드래그로 구역을 그려 원하는 비율 설계
```
